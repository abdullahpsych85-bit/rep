# القيادة التكتيكية — تطبيق العميل (v1.1)

تطبيق ويب قابل للتثبيت على الهاتف (PWA) يعمل دون إنترنت، مبني على بطاقة «لوحة القيادة التكتيكية»،
ومصمَّم ليستخدمه العميل **في لحظة الموقف** ثم **يوثّقه** لمراجعته في الجلسة.

## ما الذي يفعله

| الشاشة | الوظيفة |
|---|---|
| **أنا في موقف الآن** | ٤ خطوات ثم تقييم ختامي: الرصد المبكر (المؤشرات + شدة الاستثارة) ← الإيقاف التكتيكي (موجِّه تنفس ٣ دورات: شهيق ٤ث / زفير ٦ث) ← الاحتواء المعرفي ← إجراء توجيهي (سؤال واحد) ← تقييم الاستثارة بعد التدخل. **قابل للاستكمال**: تُحفظ الحالة مع كل تغيير، ويُستأنف الموقف غير المكتمل خلال ساعة من آخر تفاعل، ثم يبدأ موقف جديد تلقائياً |
| **تسجيل موقف** | نوع المحفز، الموقف، التقييم التلقائي، الاستثارة قبل/بعد، السؤال المطروح (حقل مستقل)، البروتوكول، الاستجابة البديلة، و«ماذا حدث في سلوكي فعلاً؟» (طرح سؤالاً / لم يقاطع / بقي حاضراً / لم يبخّس). كل حقل يُحفظ تلقائياً في مسودة تبقى بعد إغلاق التطبيق |
| **الأرشيف** | بطاقات السجلات، حذف فردي أو كلي مع **تراجع** (٨–١٠ ثوانٍ)، تصدير CSV (يفتح في Excel بالعربية)، نسخة احتياطية JSON واستعادتها دون تكرار |
| **التقدم** | **المؤشرات السلوكية أولاً**: نسبة المواقف دون سلوك دفاعي، ونسب طرح السؤال وعدم المقاطعة والحضور وعدم التبخيس وتطبيق البروتوكول (محسوبة فقط على السجلات التي سُجّل فيها السلوك). ثم: عدد المواقف، آخر ٧ أيام، متوسط الاستثارة، و«متوسط التغيّر في الاستثارة» (تقدير ذاتي قبل/بعد، يُعرض كمؤشر مساعد لا كمقياس نتيجة) |
| **البطاقة المرجعية** | المحتوى الأصلي كاملاً (الرصد، التحليل، التكلفة، البروتوكول) |

## الخصوصية

- السجلات تُحفظ في `localStorage` على جهاز العميل فقط، ولا يرسلها التطبيق إلى أي خادم. المشاركة مع المعالج يدوية عبر التصدير.
- **لا اتصال بأي جهة خارجية**: الخط (Cairo، رخصة SIL OFL — `fonts/OFL.txt`) مستضاف داخل التطبيق، ولا توجد مكتبات CDN أو تحليلات.
  وتفرض سياسة `Content-Security-Policy` في الصفحة ذلك تقنياً (`default-src 'self'`، `connect-src 'self'`).
- الجهة الوحيدة التي يتصل بها الجهاز هي موقع الاستضافة عند تحميل التطبيق (وهي ترى عنوان IP كأي موقع)، ولا ترى السجلات.
- يطلب التطبيق من المتصفح تخزيناً دائماً (`navigator.storage.persist`) لتقليل خطر حذف البيانات، لكن حذف بيانات المتصفح أو إزالة التطبيق يحذف السجل؛ لذا يُنصح بالنسخ الاحتياطي الدوري.
- الجهاز نفسه غير مشفّر من قِبل التطبيق: من يفتح الهاتف يستطيع فتح السجل. قفل الشاشة مسؤولية العميل، ويُنبَّه إلى ذلك عند التسليم.

## بنية البيانات (schemaVersion 2)

| المفتاح | المحتوى |
|---|---|
| `tactical_logs_v2` | `{ schemaVersion: 2, savedAt, logs: [Entry] }` |
| `tactical_draft_v2` | مسودة نموذج التسجيل الكاملة |
| `tactical_moment_v2` | حالة الموقف الجاري (الخطوة، المؤشرات، الاستثارة، السؤال) |

`Entry = { schemaVersion, id, ts, source (moment|manual|legacy), trigger, situation, thought, signals[], before, after, question, protocol, behaviors{asked, noInterrupt, present, noDevalue} | null, response }`

**الترحيل التلقائي V1 → V2**: عند أول تشغيل، إن لم يوجد `tactical_logs_v2` تُقرأ سجلات `tactical_logs_v1`
(اللوحة الأصلية أو الإصدار 1.0)، وتُحوَّل (`intensity` ← `before`، والمعرّف إلى نص، و`source: legacy`) ثم تُكتب في v2.
يُترك مفتاح v1 دون تعديل كنسخة احتياطية ولا يُكتب فيه مجدداً. الاستيراد يقبل ملفات v1 (مصفوفة) وv2.

## النشر (لإعطاء العميل رابطاً يثبّته)


**التثبيت عند العميل:**
- Android (Chrome): يظهر زر «تثبيت» في الصفحة الرئيسية، أو من القائمة ← «تثبيت التطبيق».
- iPhone (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

بعد التثبيت يظهر اختصاران عند الضغط المطوّل على الأيقونة (Android): «أنا في موقف الآن» و«تسجيل موقف».

## الملفات

- `index.html` — التطبيق كاملاً (HTML/CSS/JS دون مكتبات خارجية)
- `fonts/` — خط Cairo (عربي + لاتيني، ٤ أوزان) ورخصته
- `sw.js` — Service Worker للعمل دون إنترنت
- `manifest.webmanifest`، `icon.svg`، `icon-192.png`، `icon-512.png` — بيانات التثبيت والأيقونات
- `tests/smoke.js` — اختبار شامل للمسارات

عند تعديل أي ملف بعد النشر، غيّر قيمة `CACHE` في `sw.js` (الحالية `tactical-v2`) ليحصل العملاء على النسخة الجديدة.

## الاختبار

```bash
npx http-server -p 8765 -s .        # في نافذة منفصلة
node tests/smoke.js                  # يتطلب playwright
```

يغطي ٤١ فحصاً: الترحيل من v1، استكمال الموقف وانتهاء صلاحيته بعد ساعة، المسودة بعد إعادة التحميل،
الحفظ، تهريب النصوص (XSS)، الحذف والتراجع، تصدير CSV/JSON، المسح والتراجع، الاستيراد دون تكرار،
مؤشرات التقدم، العمل دون إنترنت عبر Service Worker، وعدم وجود أي طلب لجهة خارجية أو خطأ CSP.
