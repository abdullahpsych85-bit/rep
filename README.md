# القيادة التكتيكية — تطبيق العميل

تطبيق ويب قابل للتثبيت على الهاتف (PWA) يعمل دون إنترنت، مبني على بطاقة «لوحة القيادة التكتيكية»،
ومصمَّم ليستخدمه العميل **في لحظة الموقف** ثم **يوثّقه** لمراجعته في الجلسة.

## ما الذي يفعله

| الشاشة | الوظيفة |
|---|---|
| **أنا في موقف الآن** | مسار موجَّه من ٤ خطوات: الرصد المبكر (اختيار المؤشرات الجسدية/الذهنية/السلوكية + شدة الاستثارة) ← الإيقاف التكتيكي (موجِّه تنفس ٣ دورات: شهيق ٤ث / زفير ٦ث) ← الاحتواء المعرفي ← إجراء توجيهي (سؤال واحد) ← تقييم الاستثارة بعد التدخل |
| **تسجيل موقف** | نموذج السجل: نوع المحفز، الموقف، التقييم التلقائي، الاستثارة قبل/بعد، هل طُبّق البروتوكول، الاستجابة البديلة. يُملأ تلقائياً من المسار اللحظي |
| **الأرشيف** | بطاقات السجلات، حذف فردي، تصدير CSV (يفتح في Excel بالعربية)، نسخة احتياطية JSON واستعادتها |
| **التقدم** | عدد المواقف، مواقف آخر ٧ أيام، متوسط الاستثارة، متوسط الانخفاض بعد الاستجابة، نسبة تطبيق البروتوكول، أكثر المحفزات والمؤشرات تكراراً |
| **البطاقة المرجعية** | المحتوى الأصلي كاملاً (الرصد، التحليل، التكلفة، البروتوكول) |

## الخصوصية

كل البيانات تُحفظ في `localStorage` على جهاز العميل فقط، ولا يوجد أي خادم أو إرسال بيانات.
المشاركة مع المعالج تتم يدوياً عبر التصدير. حذف بيانات المتصفح يحذف السجل، لذا يُنصح بالنسخ الاحتياطي الدوري.
السجلات المحفوظة بالنسخة الأصلية من اللوحة (المفتاح `tactical_logs_v1`) تُقرأ تلقائياً إن كانت على نفس النطاق.

## النشر (لإعطاء العميل رابطاً يثبّته)

التطبيق ملفات ثابتة فقط، ويحتاج استضافة عبر HTTPS ليعمل التثبيت والعمل دون إنترنت:

1. **GitHub Pages**: Settings ← Pages ← Source: `Deploy from a branch` ← اختر الفرع والمجلد `/ (root)`.
   (المستودع الخاص يحتاج اشتراكاً مدفوعاً لتفعيل Pages، أو اجعله عاماً — لا يحتوي أي بيانات عملاء.)
2. أو ارفع المجلد كما هو إلى Netlify / Cloudflare Pages / Vercel.

**التثبيت عند العميل:**
- Android (Chrome): يظهر زر «تثبيت» في الصفحة الرئيسية، أو من القائمة ← «تثبيت التطبيق».
- iPhone (Safari): زر المشاركة ← «إضافة إلى الشاشة الرئيسية».

بعد التثبيت يظهر اختصاران عند الضغط المطوّل على الأيقونة (Android): «أنا في موقف الآن» و«تسجيل موقف».

## الملفات

- `index.html` — التطبيق كاملاً (HTML/CSS/JS دون مكتبات خارجية؛ خط Cairo اختياري مع بديل من خطوط النظام)
- `sw.js` — Service Worker للعمل دون إنترنت
- `manifest.webmanifest`، `icon.svg`، `icon-192.png`، `icon-512.png` — بيانات التثبيت والأيقونات

عند تعديل أي ملف بعد النشر، غيّر قيمة `CACHE` في `sw.js` (مثلاً `tactical-v2`) ليحصل العملاء على النسخة الجديدة.
